## Docufi Mini-Chat

This project implements a full-stack AI application (Flask-React + TS) that:

- Accepts document uploads
- Extracts key financial facts (Revenue, EBITDA, YoY growth)
- Enables users to chat with the document content after uploading process.

## 📦 Project Structure

- `backend/`: Python Flask server with LangChain-powered extraction
- `frontend/`: React + TypeScript interface for file upload and conversation with chatbot
