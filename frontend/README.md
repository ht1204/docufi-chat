# 🌐 Frontend – Docufi Mini-Chat (React + TypeScript + Vite)

This is the frontend interface for the **Docufi Mini-Chat** project.

- Built with **React**, **TypeScript**, and **Vite**
- Allows users to upload financial documents (PDFs)
- Displays a chat interface to interact with an AI agent using extracted data

---

## ⚙️ Tech Stack

- React 18 (via Vite)
- TypeScript
- Vite
- Node.js 22+
- CSS Modules

---

## Getting Started

### 1. Install dependencies

```bash
cd frontend
npm i
```
###  2. Run the development server
```bash
npm run dev
```

### 3. Configure backend communication
Go to `utils.ts` file and check variable `API_URL` to set the backend api url aligned to your custom settings.
